# Revara

In the year 2022 alone, humans produced 62 million tonnes of e-waste that includes all of the electronics combined. Only 22.3% of the 62 million tonnes of e-waste was recycled, that means only 13.8 million tonnes of waste is recyled and the remaining ~48.2 tonnes just lives unrecycled polluting the environment we live in. According to [this report by WHO](https://www.who.int/news-room/fact-sheets/detail/electronic-waste-(e-waste)).

> Thats `62,000,000,000` kg and `136,686,602,555` lb. **Limited repair options is a major contributor in this.**

To Achieve maximum repairability, we built Revara.
Across all majorly used computer accessories like Keyboards, Mice etc,. with support for more accessories in the future.

Inspired by [Framework](https://frame.work/), we prioritize repairability, customizability, and user satisfaction over everything.

Currently Supporting only Keyboards. Customize Everything.

- Case
- Hot-swap sockets
- even the Matrix PCB! (Custom PCB is used here which you can find somewhere here)
- controller
- battery
- if anything remains, that too.
